## 👨‍💻 About Me

Hello! I am **Dileep Kumar**, a dedicated and results-driven **Desktop Support Engineer**. I specialize in enterprise Windows operating system diagnostics, hardware lifecycle support, LAN/WAN network configuration, active domain management, and automating repetitive administrative workflows.

- 🖥️ **Operating System Diagnostics:** Advanced troubleshooting of Windows 10/11, event log forensics, registry repairs, crash dump analysis, and OS recovery.
- 🏢 **Identity & Directory Administration:** Domain user provisioning, permission delegation, and policy enforcement via **Active Directory (AD)** and **Group Policy Objects (GPO)**.
- 🔌 **Hardware & Infrastructure Diagnostics:** Component diagnostics, POST failure resolution, BIOS/UEFI firmware configuration, and thermal/power supply testing.
- 🌐 **Network Protocol Support:** Subnet configuration, TCP/IP stack resets, DNS flushing, DHCP reservation management, and VPN connectivity triage.
- 📡 **Remote Technical Assistance:** High-availability incident response, ticket lifecycle management, and remote troubleshooting via RDP, AnyDesk, and TeamViewer.
- 🤖 **Automation & Software Development:** Crafting PowerShell and Batch utilities for unattended deployments, plus developing Python and AI-driven desktop utilities.
